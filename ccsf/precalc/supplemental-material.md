# writing exercises

FILLINTHEBLANK style

In the question, use `\(\)` for inline math and `\[\]` for display math.
Use `{blank}` for the blank

In the answer field, use regex. for example,
`-2\s*,\s*-3|3\s*,\s*-2`
the `\s*` allows any number of spaces there, and the `|` is an 'or'
