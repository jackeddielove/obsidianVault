# Theorem

The integral test says that series$$\sum_{n=N}^\infty f(n)$$converges if and only if the improper integral$$\int_N^\infty f(x)\, dx$$converges.

# Examples

The series$$\sum_{n=1}^\infty \frac{1}{n^2}$$converges because the improper integral$$\int_1^\infty \frac{1}{x^2}\, dx$$converges, and the series$$\sum_{n=1}^\infty \frac{1}{n}$$diverges because the improper integral$$\int_1^\infty \frac{1}{x}\, dx$$diverges.

You have to do the integrals to see if they converge or not. This is usually the laborious part.
