# structure idea
Do something
Watch something
Make something
Write something
Use something

# themes
- abstraction
- models/symbols/diagrams
- experimentation/making
- logic/proof/structure
- language/communication

# topics
## combinatorics
1. Do something: counting high fives
2. Watch something: watch catalan patterns grow
3. Make something: make catalan artwork
4. Write something: write down a catalan identity
5. Use something: make a catalan sketch in p5

## fractals
1. Do something: clap out integer sequences
2. Watch something: iterations of a fractal
3. Make something: fractal or menger sponge drawing
4. Write something: find the dimension of a fractal
5. Use something: make a fractal sketch in p5

## matrices
1. Do something: apply matrix transformations
2. Watch something: watch 2-d, 3-d, 4-d transformations
3. Make something: 2-d transformation of a drawing
4. Write something: find a matrix inverse
5. Use something: use a matrix calculator

## imaginary numbers
1. Do something: complex number dance
2. Watch something: iterations of a fractal
3. Make something: color squares based on function on C
4. Write something: multiplication/addition/inverses in C
5. Use something: use p5 for a more complex version of 3

## infinity
1. Do something: xeno’s paradox your way toward your seat
2. Watch something: conic sections or something, meeting at infinity
3. Make something: stereographic projection or poincare disc model or projective drawing
4. Write something: equation(s) related to 3.
5. Use something: desmos animation with infinity mapped to some number

## higher dimensions
1. Do something: move around in 1-, 2-, 3-dimensional space... try to move in a fourth dimension
2. Watch something: animations of 4-d shapes
3. Make something: drawing or model of 4-d shape
4. Write something: a formula for the number of k-faces of an n-cube
5. Use something: desmos 3-d for slices of 4-d surfaces

## symmetry
1. Do something: move 2- or 3-d shapes around to match up with a given one
2. Watch something: animations of different kinds of symmetry
3. Make something: a platonic solid
4. Write something: the cayley table, or maybe a group word and its reduction
5. Use something: sagemath for the symmetry group of your solid
