# Definitions

## homeomorphism

A function $f: X\to Y$ between topological spaces is a **homeomorphism** if
- $f$ is a bijection
- $f$ is continuous
- $f^{-1}$ is continuous

## diffeomorphism

A continuously differentiable map $f:M\to N$ between differentiable manifolds is a **diffeomorphism** if it is a bijection and its inverse is differentiable.

## immersion

A differentiable function $f:M\to N$ between differentiable manifolds is an **immersion** if its differential pushforward is everywhere injective.

(A diffeomorphism is a bijective immersion, perhaps with some obscure counterexamples)

## embedding

A function $f:X\to Y$ between topological spaces is an **embedding** if $f:X\to f(X)$ is a homeomorphism.
