## animation upon new slide
The following is for an animation that happens as soon as a counter function achieves a specified value
### before setup();
If you're using slides and want the animation to start at the same place whenever you get to its slide, make sure the arrow keys reset 's' to 0.
~~~
let s = 0;
function keyPressed() {
	if (keyCode === RIGHT_ARROW) {
		s = 0;
	}
	if (keyCode === LEFT_ARROW) {
		s = 0;
	}
	return false;
}
~~~

### inside draw();
The function $$(1-t)\cdot\text{start-state}+t\cdot\text{end-state}$$animates start-state to end-state as $t$ goes from 0 to 1.
Also, the function$$\text{map}(n, a, b, c, d)$$takes a number $n$ relative to $a$ and $b$ and returns its analog relative to $c$ and $d$.
Putting these together, we can make something like this example, which animates a circle from (0,0) to (350,0) as 's' (which increases every frame) goes from 0 to 100. Make the upper bound on 's' smaller for faster animation.

~~~
if (counter == 4) {
	if (s <= 100) {
		let t = map(s, 0, 100, 0, 1);
		ellipse((1-t)*0+t*350,0,50,50);
	}
	else {
		ellipse(350, 0, 50, 50);
	}
	s++;
}
~~~

### inside draw();

The function $$(1-t)\cdot\text{start-state}+t\cdot\text{end-state}$$animates start-state to end-state as $t$ goes from 0 to 1.
Also, the function$$\text{map}(n, a, b, c, d)$$takes a number $n$ relative to $a$ and $b$ and returns its analog relative to $c$ and $d$.
Putting these together, we can make something like this example, which animates the map $S^1 \to S^1$ by identifying antipodal points.

~~~
if (keyIsDown(RIGHT_ARROW)) {
	s = constrain(s + 0.01, 0, 1);
}
if (keyIsDown(LEFT_ARROW)) {
	s = constrain(s - 0.01, 0, 1);
}
noFill();
beginShape();
	for (let t = 0; t < TWO_PI; t += 0.01) {
		let X0 = Math.cos(t);
		let Y0 = Math.sin(t);
		let X1 = Math.pow(X0, 2) - Math.pow(Y0, 2);
		let Y1 = 2*X0*Y0;
		let Xs = (1-s)*X0 + s*X1
		let Ys = (1-s)*Y0 + s*Y1
		let x = map(Xs, -5, 5, -width/2, width/2);
		let y = map(Ys, -5, 5, width/2, -width/2);
		vertex(x, y);
	}
endShape();
~~~
  
## graphing curves

Use noFill();
### Here is the EXPLICIT curve $y=x^2$.
We  let $x$ be the horizontal pixel location and let it vary across the screen. At every point we define algX to be the horizontal location in our coordinate system, and we let algY be the function of $x$ that we want to graph. Then we map algY back into pixels.
~~~
beginShape();
for (let x = -width/2; x < width/2; x++) {
let algX = map(x, -width/2, width/2, -5, 5);
let algY = Math.pow(algX, 2);
let y = map(algY, -5, 5, width/2, -width/2);
vertex(x, y);
}
endShape();
~~~
### Here is the IMPLICIT curve $x^2-y^2=1$
Same idea as above, but drawing two separate curves and using x as functions of y

~~~
beginShape();
for (let y = -height/2; y < height/2; y++) {
let algY = map(y, -width/2, width/2, 5, -5);
let algX = Math.sqrt(Math.pow(algY, 2) + 1);
let x = map(algX, -5, 5, -width/2, width/2);
vertex(x, y);
}
endShape();

beginShape();
for (let y = -height/2; y < height/2; y++) {
let algY = map(y, -width/2, width/2, 5, -5);
let algX = -Math.sqrt(Math.pow(algY, 2) + 1);
let x = map(algX, -5, 5, -width/2, width/2);
vertex(x, y);
}
endShape();
~~~
